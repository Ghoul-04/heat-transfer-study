# Heat Transfer Study (3rd stage, Chemical Engineering)

An interactive study site built from the lecture notes. Explanations are in Arabic, and formulas and worked examples are in English.

- Static site with no build step. Open `index.html` or use GitHub Pages.
- KaTeX for the math. Interactive models are plain SVG and JavaScript (`js/models.js`, `js/physics.js`).
- `node verify/verify.js` recomputes every worked answer from the lectures.
- `node verify/serve.js` runs a local preview at http://localhost:5178.

The lecture PDFs themselves are not included in this repository.
